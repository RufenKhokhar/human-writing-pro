# Contributing

Open an issue describing the writing problem, intended audience, host/model,
and a short reproducible example. Remove private information before posting.

For a pull request, change the canonical files in `skills/human-writing-pro`.
Keep instructions focused: prefer a demonstrated decision improvement over a
longer blacklist. Preserve facts and user intent. Cite original sources for new
research claims and distinguish experiments from opinion or vendor claims.

Run validation and tests, then run `scripts/build.py` to regenerate the portable
prompt. Do not hand-edit generated prompt files. Include the expected behavior
and any limitations in the pull request. New host integrations should cite the
host's official documentation and state whether they were tested live.

Contributions are submitted under the repository's MIT license. Do not include
third-party text or code without the necessary rights and attribution.
